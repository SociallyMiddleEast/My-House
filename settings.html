Settings

Account, data sources, and dashboard customization — all in one place.
Account
This is a privacy screen, not real security. The check runs entirely in this browser's JavaScript — anyone with dev tools open can read the stored password hash or skip the check outright. It stops a family member from casually opening the dashboard; it does not protect your DeyeCloud/Tuya data or Google Sheets access. Those stay protected by your proxy's key and your Google account regardless of whether this is on.
Data source
DeyeCloud, Tuya, LG ThinQ, and SmartThings all require a signed, secret-holding request — something a public GitHub Pages site can't safely do alone. This dashboard talks to a small backend proxy you deploy yourself (see /server in the project). The proxy holds your real API keys; the browser only ever knows its URL.
Integrations
Google Sheets sync

One connection, shared by Pantry and Expenses — each writes to its own tab (named exactly Pantry and Expenses) in the same Sheet. Setup is one-time in Google Cloud Console: enable the Sheets API, create an OAuth Client ID ("Web application") with this site's URL under Authorized JavaScript origins, and add your own Google account as a test user on the OAuth consent screen. You'll see an "unverified app" warning when connecting — expected for a personal app.

Custom gauges

Add your own tiles to Overview's Climate and Utilities sections — a pool temperature, a second water tank, whatever isn't covered above. No live data source; you (or anyone with the dashboard open) adjust the value with +/− right on Overview, or here.
