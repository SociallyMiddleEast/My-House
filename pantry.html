Google Sheets sync

Optional — keeps Pantry in sync across every device by reading and writing a Sheet you control. The buttons below don't change; they'll just read from and write to this Sheet instead of only this browser. Setup is one-time in Google Cloud Console: enable the Sheets API, create an OAuth Client ID (type "Web application") with this site's URL under Authorized JavaScript origins, and add your own Google account as a test user on the OAuth consent screen — otherwise sign-in will be blocked. You'll see an "unverified app" warning when connecting; that's expected for a personal app.
